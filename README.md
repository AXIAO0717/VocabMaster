# VocabMaster - 六级背单词工具

一个基于 Python + Streamlit 的六级背单词工具，支持艾宾浩斯复习、闪卡学习、拼写测试、词汇量自适应评估、错词本、翻译词汇、写作助手、造句练习等功能。

## 项目介绍

VocabMaster 是一个面向六级备考的本地背单词应用。它把单词记忆、复习调度、测试反馈和数据分析整合在一个 Web 界面里，帮助用户按遗忘曲线规律高效复习。

项目内置了一份约 2000 词的六级核心词库，也支持通过 txt 文件批量导入自定义词库。所有数据保存在本地 SQLite 数据库中，无需联网即可使用。

## 功能列表

- **艾宾浩斯复习**：根据答题情况动态计算复习间隔（1/2/4/7/15 天），答错自动重置复习进度。
- **闪卡学习**：显示单词、音标、词性，点击后查看释义和例句，支持浏览器 TTS 发音。
- **拼写练习**：根据音标、词性和中文意思拼写单词，支持回车提交和错误重练。
- **错词本**：自动收集答错和拼错的单词，支持集中复习和拼写练习。
- **词汇量测试**：8 级自适应测试，根据正确率动态升降难度，估算词汇量。
- **造句练习**：用给定单词造句，对照参考例句自评。
- **翻译词汇**：内置翻译专业术语，支持一键导入词库。
- **写作助手**：提供议论文、图表作文、建议信模板，以及连接词和高频短语。
- **学习统计**：用 Plotly 展示记忆曲线、打卡热力图、每日复习量、对错比例等。
- **批量导入导出**：支持 txt 格式词库导入导出。
- **打卡功能**：记录每日新词和复习量，计算连续打卡天数。

## 技术栈

- **语言**：Python 3.10+
- **Web 框架**：Streamlit
- **数据库**：SQLite（通过 `sqlite3` 操作）
- **数据分析**：Pandas
- **数据可视化**：Plotly、Matplotlib
- **发音**：浏览器 `SpeechSynthesis` API
- **前端交互**：注入 JavaScript 监听键盘事件
- **文本处理**：正则表达式
